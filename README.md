## Repository Structure

This GitHub profile contains two main types of repositories, distinguished by a simple naming convention:

| Prefix      | Description                                                                                           |
| ----------- | ----------------------------------------------------------------------------------------------------- |
| `RSC-` | Personal projects related to scientific research, simulations, data analysis, and experimental tools. |
| `TCH-` | Materials developed for courses, including lectures, notebooks, exercises, and examples.              |

This prefix-based structure helps keep repositories clearly organized and makes their purpose immediately identifiable.
